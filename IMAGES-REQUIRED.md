## 🎨 Image Specifications

### General Requirements:
- **Format**: PNG (preferred) or JPG
- **Background**: Transparent PNG preferred for best appearance
- **Height**: Fixed at 60px (width will scale proportionally)
- **Quality**: High resolution (at least 2x for retina displays)
- **File Size**: Optimize for web (under 100KB per image)
- **Color**: Full color logos work best

### Technical Details:
- CSS property used: `height: 60px; object-fit: contain;`
- This ensures logos maintain aspect ratio
- Logos are centered within testimonial cards
- White background on cards, so logos should work on white

## 🔧 How to Add Images

1. Obtain or create the 7 company logos
2. Resize them to approximately 60px height (or provide high-res, CSS will scale)
